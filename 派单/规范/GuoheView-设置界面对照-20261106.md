## 1. 合规声明（先读）

- **用户定制**：《设置页实时应用与控件模式》§2 末尾原写「不要求全页改成截图中的卡片样式……不视为要求照搬 GuoheView」。用户 2026-11-06 明确「可以仿一仿」，**属新的用户明确定制，覆盖该条**。所有引用本文件的派单须标注「用户定制」，并区分「原版实测」与「定制」。
- **可借鉴**：信息层级、分组方式、控件形态（拨动开关 / 卡片 / 下拉 / 按钮 / 表格）、交互节奏（实时预览、即时生效）、间距与圆角质感、说明文字的组织方式。
- **不可复制**（依据 `派单/规范/COMPAT-RULES.md`、`docs/design/QUIKVIEW-DESIGN.md` §1、`AGENTS.md`）：
  - 图标与图形资源（须 QPainter 自绘；项目已开源，版权风险）
  - 文案原文（`lang/zh-CN.lang` 不得抄入 QuikView；文案走 `hv/lang.py` + 新功能自写）
  - 蓝色云朵吉祥物等装饰性图形（docs/design §1 禁装饰性图标 / 无意义装饰）
  - 版本号、官网、QQ 群、GitHub 等产品信息
  - 超过 10px 的卡片圆角（设计规范 v1.2 第 19 行）；新增圆角档位须先在 `src/UiStyle.h` 定义并登记 §4.2
- **基准不变**：`Honeyview.exe` 仍是功能、布局、尺寸与交互基准；本文件仅作视觉质感与信息架构参考，不取代基准。
- **颜色**：一律复用 `src/UiStyle.h` 语义令牌，不从截图取色。

## 2. 整体形态（10 页共性）

| 特征 | 观察 | QuikView 现状 |
|---|---|---|
| 左侧导航 | 11 个分组、每项线性图标、选中态深色底 + 左侧蓝色竖条 | 已有分组与图标、选中底色；无蓝色竖条 |
| 导航顶部 | 设置搜索输入框；语言包含 39 条搜索同义词 | 无设置搜索 |
| 内容区 | 圆角深灰卡片分组，组标题在卡片外，卡片内左标签 / 右控件 | 平铺行 + 分隔线，无卡片 |
| 说明文字 | 几乎每个开关 / 下拉下方有一行小字说明 | 说明较少；方案 §1 要求「每个设置项有生效时机标签」 |
| 二态控件 | 胶囊轨道拨动开关（关灰 / 开蓝） | 复选框为主（外观页两个复选框写同一 `theme` 键） |
| 滚动 | 长页右侧滚动条，末端内容完整 | 键盘页曾返工底部留白（M-05） |
| 底部 | 蓝色云朵吉祥物装饰 | 无，**不借鉴** |

## 4. 与现行规范条款的对照

| 想抄的东西 | 规范依据 | 结论 |
|---|---|---|
| 胶囊拨动开关 | 设计规范 v1.2 §4.2 圆角 `10/9/6/5/4px`；docs/design §3 第 23 行「沿用已有档位」 | 可做：轨道 20px 高 / 圆角 10px，复用已登记最大档位；须在 §4.2 登记「开关轨道」新控件尺寸，不引入 15px 之类新值 |
| 卡片分组 | v1.2 第 19 行禁超过 10px 圆角；§4.2 卡片 = 9px 档位 | 圆角控制在 10px 内可合规；但**全页卡片化是视觉重构**，需单独派单 |
| 每项小字说明 | docs/design §3 第 25 / 27 行「禁用项须解释原因」「设置项需说明真实生效时机」 | **规范本来就要求**，属补齐而非新增 |
| 实时预览 | docs/design §3 第 27 行「即时预览须支持取消回滚」 | 方向一致；实现必须带会话快照与 Cancel / Esc / 关闭回滚证据 |
| 设置搜索 | 规范未覆盖 | 新功能，先评估再派单 |
| 吉祥物 / 图标 / 文案 | docs/design §1；COMPAT-RULES 视觉体系与图标条款 | **禁止** |
