# COMPAT-RULES —— 原版兼容边界

> 解决的问题：**哪些必须和 HoneyView 一样，哪些允许 QuikView 自己定。**
> 没有这份文件，每次改动都会退化成「按最近一次反馈调数值」，已验证的规则会被临时需求覆盖。

---

## 0. 判定流程（遇到分歧先走这个）

1. **实测原版**：100% DPI 下操作并截图，量出真实数值，不靠记忆和推测；
2. **记录证据**：截图 / 尺寸 / 快捷键表，落到 `交接-*.md` 或本文；
3. **定归属**：属于 A 类（必须一致）还是 B 类（自主设计）；
4. **写进本文**：新增条目必须留一行登记（日期 / 条目 / 归属 / 依据）；
5. **代码标注**：偏离原版的行为加注释 `// QV-CUSTOM: 原因`，便于后人判断「这是 bug 还是设计」。

**红规则**：临时数值不得覆盖已验证的原版规则；用户的定制需求必须单独标注，不能冒充原版行为。

## 1. A 类：必须与 HoneyView 一致（体验契约）

这些是老用户肌肉记忆，改了就是「不像原来那个软件」。

| 项目 | 规则 | 依据 |
|---|---|---|
| 空格 | 静态图 = **下一张**；动图 = 播放/暂停 | `MainWindow.cpp` keyPressEvent |
| `←` / `→` | 上一张 / 下一张 | QAction 快捷键表 |
| `Ctrl+←` / `Ctrl+→` | 多帧图（GIF / 多页 TIFF）逐帧 | `FrameNavigator` |
| Home / End | 首张 / 末张 | 快捷键表 |
| 首尾边界 | 两套语义：`stop` 停住并提示 / `first` 循环回绕，文案区分「已经是第一张」与「已回到第一张」 | `DirectoryLoader::m_edgeAction` |
| 双页配对 | 左→右 7 张/跨页、左←右 6 张/跨页 | 原版实测 |
| 翻页不重扫目录 | 序列在打开时扫描一次并驻留，切图不重扫 | `DirectoryLoader::open()` |
| 滚轮 | 画布上 = 缩放；**滑杆上** = 翻页 | 原版实测 |
| `F2` / `F5` / `F1` | 打开图片 / 设置 / 关于 | 快捷键对齐原版语言表 |
| `B` / `F3` | 添加书签 / 编辑书签 | 原版菜单项 |
| `Ctrl+K` | 锁定缩放（翻页不重新适配） | 原版语义 |
| `Z` | 拉伸小图（默认小图保持 100%） | 原版语义 |
| `0` / `*` | 回到 100% | 快捷键表 |
| `Ctrl+I` / `Ctrl+G` | 反色 / Gamma | 原版图片效果 |
| `Alt+Up` | 不旋转（真回到源图） | 原版菜单 |
| `ESC` 分层 | 取消裁剪 → 退出全屏 → 关窗口（最后一步受 `escExit` 配置控制） | `MainWindow.cpp` |
| 右键菜单分组与文案 | 以 `hv/lang.py` 的 532 条文案为单一来源 | 原版资源表 |
| 设置项默认值 | 沿用原版（例：HDR 默认关） | 原版默认配置 |

## 2. B 类：QuikView 自主（允许创新，不受原版约束）

| 项目 | 我们的做法 | 为什么自主 |
|---|---|---|
| 视觉体系 | Win11 深色、低对比细边框、轻圆角、统一线性图标、淡蓝强调 | 原版是 2013 年视觉，不能照搬 |
| 图标 | 全部 `QPainter` 自绘，不引用原版 png/dll/ico | 版权 + 高分屏清晰度 |
| 底部胶囊 | 440×72 两排浮层，显示/隐藏走 `Hidden→Showing→Visible→Hiding` 状态机 | 原版是固定控制栏；胶囊是产品差异化 |
| 顶部区域 | 28px 标题栏 + 34px 命令栏，纯浮层、不占画布 | 最大化图片显示面积 |
| 信息浮层 / 面板 | 自研布局，EXIF/GPS/直方图 | 原版是内嵌网页控件 |
| 设置页结构 | 九类分组，零消费项**灰显不隐藏** | 明确产品态度：不做假开关 |
| 主题 | 深 / 浅两套可切换 | 原版只有皮肤机制 |
| 检查更新 | GitHub Releases，手动 + 启动自动（默认关、24h 频控） | 原版走 `ver.bandi.so`，已停更 |
| HDR 色调映射 | 新增能力 | 原版无 |
| 文案 | 原版有的走 `lang.py`；新功能自写 | 语境不同 |
