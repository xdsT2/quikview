## 1. 迁移结论（4 项，同页一批）

按监工侧口径：会话内可见项做即时预览 + 取消回滚；模态阻断 / 只在下一次操作生效的项按「保存生效型」迁移，并在控件旁标注真实生效时机。未凑数，4 项均有真实运行时消费点。

| 键 | 控件 | 类型 | 真实生效时机（已写在控件旁） | 本次证据 |
|---|---|---|---|---|
| `view/show_anim_control` | 不显示动画信息控制 | **即时预览**（SET-02 LiveCheck） | 切换后底部信息行「第 n/N 帧」立刻显示/隐藏；保存后持久化；取消/Esc/✕ 恢复进入设置前的值 | 双向 + 会话内预览 + 重启读回 + 三链路 + 失败注入 |
| `view/overlay_filename` | 顶端菜单隐藏时显示文件名 (Shift+TAB) | 保存生效型 | 保存后，下一次隐藏顶端菜单并按 Shift+TAB 时读取 | 双向 + 重启读回 + 三链路 + 模态阻断佐证 |
| `view/save_zoom_state` | 保存缩放状态 | 保存生效型 | 保存后，下次打开图片或重启时按记录恢复；当前画面不变 | 双向（156% / 100%）+ 重启读回 + 三链路 |
| `view/show_tooltip` | 不显示鼠标悬浮工具提示 | 保存生效型 | 保存后，下一次鼠标悬停时读取 | 双向 + 重启读回 + 三链路 + 模态阻断佐证 |
