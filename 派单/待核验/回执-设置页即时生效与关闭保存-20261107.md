## 一、补真实即时生效（快捷键「启用」）

### 改了什么
- `MainWindow::applyLiveSetting()` 新增 `keyboard/*_enabled` 分支：在「启用」切换点直接调用 `applyShortcutConfig()` 重装 14 个动作的热键表；配置由设置页先写入，运行态不再等 `onSettings()`（对话框关闭后）重放。
- `SettingsDialog` 键盘「启用」`toggled`：先经唯一写盘入口 `applyInstantValue()` 落配置，再立即 `host->applyLiveSetting()`；失败时回退控件与配置并提示。
- 其余即时项核对：`always_on_top`、侧边箭头、缩放/动画浮标、小字体 EXIF、主题、磨砂材质原本已是「运行态先行、成功后再写配置」；普通开关/下拉为「下一次操作/下一张图生效」，界面文案已标注时机；未发现第二个「只写配置、运行态没跟上」的即时项。

### 用什么证明
1. **切换点即重装（进程内键位表，设置页未关闭）**：`--smoke` 以 `settingspage:5,report,report,report` 打开设置页，三次快照均在对话框仍打开时采集：
   - 基线：`open=Ctrl+O|F2`
   - 关掉「启用」后：`open=-`
   - 开回后：`open=Ctrl+O|F2`
   - `settings_open=true`。证明重装发生在切换点，不是关窗。
2. **真实按键（模态真实路径）**：F5 打开设置页 → 键盘页关掉「打开」的启用（配置写入 `false`）→ 直接关闭（无草稿）→ 真实按 `Ctrl+O`：未出现「打开图片」对话框；再 F5 → 开回（配置 `true`）→ 直接关闭 → 真实按 `Ctrl+O`：出现「打开图片」对话框。
   - 按键方式：鼠标点击真实坐标、`keybd_event` 注入等价物理按键事件。
   - 证据字段：`enabled_after_off=false / enabled_after_on=true / file_dialog_after_close_off=false / file_dialog_after_close_on=true`。

### 失败与未测
- **模态限制（如实记录）**：设置页为应用模态（`setModal(true)`），打开期间主窗口收不到快捷键；实测模态态按 `Ctrl+O` 不弹任何对话框（`file_dialog_during_modal=false`）。因此「设置页仍开着时按主窗口热键」在产品里不可观察，不能作为开关生效证据；本轮改用「不关页的键位表快照 + 关闭后同会话真实按键」组合证明。
- 未测：真实物理键盘（注入事件与真实鼠标点击已覆盖操作路径）；未测 150%/200% 缩放。

## 二、统一关闭时的保存处理

### 改了什么
- **唯一写盘入口**：新增 `commitValues()` / `flushPendingWrites()`；即时项、主题、磨砂、兼容桥键、保存并关闭、直接关闭、不保存全部经此。删除 `sSet/bSet/iSet` 与 `onAccepted()` 整表写回，设置页内不再有第二套写盘。
- **只提交实际变更的键**：`onAccepted()` 只提交
  - `keyboard/<action>_key`：与进入设置时基线不同者；
  - `keyboard/<action>_action`：仅历史残留值与目标动作不一致时清理；
  - `language`：与基线不同时；
  即时项已在变更点落盘，不重复写；兼容桥键仅推导值不同才写。
- **关闭路径检查写盘错误**：`reject()` 的「直接关闭（无草稿）」与「不保存」在 `flushPendingWrites()` 后检查 `QSettings::status()`；失败弹「保存失败：配置文件写入失败(n)。改动仍保留在界面上，可稍后重试。」并**留在设置页**，不关窗。
- **重试真实可用**：Qt `QSettings::status()` 会被首个错误粘住（实测权限恢复后 sync 已写入但仍返回 AccessError）。`Config::reopenSettings()` 重建同路径实例，`flushPendingWrites()` 在失败时快照并重放全部内存键后再 sync，权限恢复后的重试可真正落盘，且不丢主窗口刚写入的键。

### 用什么证明
- `K_ok_nochange`：无改动点「保存并关闭」→ 关窗、无确认、`file_hash_same=true`、键值差异为空（未整表重写）。
- `D_save`：改「启用」+ 改热键 → 差异恰为 `keyboard/open_enabled`、`keyboard/open_key`，无 `_action`、无其他键。
- `O_lang_save`：只改界面语言 → 差异恰为 `language`。
- `A_nochange` / `J_reset` / `H_conflict` 等：直接关闭/恢复默认/冲突拦截均按预期，未回归。
- `I_fail`：保存时写盘失败（目录 ACL 拒绝 WD/AD）→ `warning=true`、`settings_open=true`、`closed=false`（留窗）。
- `L_direct_close_fail`：即时项写盘失败后直接关闭 → 警告并留窗；恢复权限后再点 ✕ → `retry_warning=false`、`retry_closed=true`、`retry_enabled=false` 已落盘（155 字节）。
- `M_discard_fail`：有热键草稿点「不保存」且写盘失败 → 警告并留窗。
- `C_mixed`：启用即时项在「不保存」后保留（`false`），热键草稿丢弃；`F_continue`：继续编辑保留草稿；`E_discard`：语言草稿丢弃；`G_revert`：改回原值后无待保存、无确认框。
- 16 个场景（A–J + K/L/M/O + N0/N2）在该 exe 上均 `exit=0`；其中 `N0_state` 在整批顺序执行时因 smoke 定时与点击竞争首轮未点到开关，同一 exe 单独复跑的通过结果已追加记录（`round3-results.txt` 末尾）。

### 失败与未测
- 写盘失败用目录 ACL 拒绝 WD/AD 制造，未覆盖磁盘满、只读卷、网络盘。
- 未测：界面语言保存后的真实重启切换（上轮遗留）、系统操作按钮的外部副作用、浅色主题下九场景交互、150%/200% 缩放。
