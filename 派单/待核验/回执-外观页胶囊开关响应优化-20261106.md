# 回执：外观页胶囊开关响应优化（2026-11-06）

## 结论

- 命中区：外观页三个开关的标题、说明、行内空白现在与轨道同属一个命中区，
  一次点击只激活一次；禁用行点任何位置都无效；按下后移出再松开取消。
- 开关可见反馈（激活 → 开关首帧，进程内自绘；并有 60fps 录屏对账）：
  - 深浅互换：P95 **305.43ms → 0.59ms**（后续 20 次，失败 0）。
  - 跟随系统 / 手选等色：P95 **304.43ms → 0.94ms**（并完全跳过换肤）。
- 等色切换（手选深色 ↔ 跟随系统且系统为深色）已证明：全局调色板重装
  **0 次**、全局样式重装 **0 次**（20/20 次点击均走等色跳过）。
- 真正变色（深 ↔ 浅）仍为一次全局换肤 + 一次对话框局部 QSS，无重复刷新；
  主题完成 P95 286.9ms，剩余耗时集中在 `QApplication::setStyleSheet`
  （P95 230.6ms）与 `dialogQss`（P95 53.6ms），见下表明细。
- 回归：空格切换、移出松开、禁用行、Esc / 标题栏关闭 / 取消回滚、保存后
  重启读回、100% 与 125% 缩放全部通过。

## 测量方法

- 临时 env 门控探针（`QUIKVIEW_UI_PROBE=1`，仅在 `build-perf` 的测量构建中使用，
  **已全部移除、未进入任何提交**）：
  - 起点：`PillToggle` 激活入口（鼠标松开命中 / 空格均经 `nextCheckState`）。
  - 开关首帧：激活后第一次 `PillToggle::paintEvent`（真实自绘，不是 `update()` 调用时刻）。
  - 主题完成：延迟下发结束 + 局部 QSS 重装；再记录下一轮事件循环时刻。
  - 阶段拆分：`setPalette` / `appQss()` 构建 / `setStyleSheet` / 对话框 `dialogQss`；
    另对每次换肤统计调色板与样式重装次数。
- 交互：`PostMessage` 点击（客户端坐标）；每场景 20 次有效切换，间隔 1.1s；
  首次与后续分别统计；失败 = 激活次数少于点击次数（三场景均 0 失败）。
- 上屏时间：`ffmpeg gdigrab` 60fps 录屏（`swap-feedback.mp4`），逐帧取样开关轨道：
  点击后约 **1 帧**（≤17ms）轨道由灰变蓝，整页浅色在 **第 79 帧**（约 283ms）完成，
  与进程内 0.48ms / 280ms 同量级，未把 `update()` 当上屏。

## 改动文件与位置

- `src/SettingsDialog.cpp`
  - `ToggleRowHitFilter`（整行命中，约 L940）：标题/说明/空白按下→松手命中同一次
    `click()`；移出取消；禁用行吞事件不激活。
  - `addToggleRow` 约 L1010–1016：标题、说明、行安装过滤器与手型光标；
    轨道尺寸、44 行高、令牌均未改；未给轨道装过滤器，避免双激活。
  - `themeMode()`（约 L931）：来源值 → 实际配色（system 按系统深浅解析）。
  - `applyThemePreview()`（约 L1353）：来源状态立即写入 `Theme::currentSetting()`；
    等色只更新来源与依赖控件并作废在途请求，**不调用**全局换肤；真变色排队
    `QTimer::singleShot(0)`。
  - `applyPendingTheme()`（约 L1381）：重任务延迟下发；`serial` 丢弃被新点击/回滚
    取代的旧请求；失败回退到运行态实际值。
  - `flushPendingTheme()`（约 L1415）：保存前同步落地，避免“配置浅色、界面未换”。
  - `saveAppearance()` 约 L1298：写盘前 flush。
  - `rollbackThemePreview()` 约 L1425：先作废在途请求再按快照同步恢复。
  - 系统主题变更处理增加 `m_themePendingActive` 守卫。
- `src/SettingsDialog.h` 约 L204–218：新增待下发/已应用状态与串行号声明。
- 未改：`fd8cc63` 的 hover 行、“保存设置”按钮、键盘页行高 32+1 与吸附、
  操作列 6px、`src/PillToggle.*`、`src/UiStyle.h` 令牌；无裸色值。
