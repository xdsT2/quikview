# 回执 - SET-04 阶段B 鼠标页 / 书签页二态项胶囊化 批次5（20261107）

## 结论

- 批次范围：鼠标页 2 项 + 书签页 1 项，共 **3 项**二态开关换成 `PillToggle`，控件旁标注「保存后生效」及真实生效时机。
- 迁移类型：**保存生效型**。三项都只在画布鼠标事件 / `openFile` 路径读取配置，模态 `dlg.exec()` 期间看不到画布，无视觉 setter，也不走 `applyLiveSetting`。
- 三项均补齐**真实进程双向运行态证据**（外部鼠标注入 + 真实窗口）：
  - 双击最大化：开 → 窗口 `1400x1114 → 2560x1392`（最大化）；关 → 保持 `1400x1114`。
  - 两侧单击翻页：开 → 右边缘单击后 `idx=2/5 → 3/5`；关 → `idx=2/5` 不变。
  - 自动书签：开 → `openFile` 后 `favorites` 写入被打开图片路径；关 → `favorites` 不出现。
- 保存→重启读回成立（三键读到保存值，控件状态截图一致）；取消 / Esc / 标题栏 ✕ 三条链路**目标键** `changed=0`。
- **未凑数**：`bookmark/max_bookmarks` 为 COMBO（下拉），不属二态开关，未纳入本批。
