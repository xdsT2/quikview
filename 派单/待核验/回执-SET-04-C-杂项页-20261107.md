## 1. 迁移口径与实现

杂项页可实测的二态项均为「保存生效型」：无视觉 setter、对话框内不可见，行为发生在下次开图/开 RAW/开 JPEG 时。本批新增一条时机说明，逐项写死：

- `etc/fit_window_to_image`：保存后，下次打开图片时按图调窗。
- `etc/no_raw_load`：保存后，下次打开 RAW 时禁用解码。
- `etc/skip_raw_when_jpg`：保存后，下次打开 JPEG 时过滤同名 RAW。
- `etc/pageturn_wav`：保存后，下次翻页时生效（未测，见 §4）。
- `etc/raw_thumbnail`：保存后，下次打开 RAW 时生效（未测，见 §4）。
- `etc/disable_screensaver`：保存后即作用于系统，退出 QuikView 后恢复（未测，见 §4）。

## 2. 逐项运行态取证

隔离配置：每场景 `QUIKVIEW_CONFIG_PATH` 指向 `Temp/set04c/*.ini`；主仓 `build/config.ini` 哈希前后一致（`3a44b948…2e6a`，见 `logs/fix-misc.jsonl`）。

### fit_window_to_image（名义：根据图片大小调节窗口大小）

| 链路 | 结果 |
| --- | --- |
| 默认开 | 960×600 图 → 窗口 **960×764**（`win=960x764 fitWin=1`，`shots/misc-fit-on.png`） |
| 保存关 | 键 `true→false`，窗口回到 **1080×815**（`shots/misc-fit-off.png`） |
| 取消链路 | 键未变（默认 true），窗口仍 **960×764**（`shots/misc-fit-cancel.png`） |
| 反向保存开 | 键 `false→true`，窗口 **960×764**（`shots/misc-fit-back-on.png`） |

### skip_raw_when_jpg（JPEG 打开时，不打开同名 RAW）

样本目录：`Temp/set04c/pair`（`p.jpg` + 同目录 `p.cr2`，无有效 RAW 内容，仅用于目录计数）。

| 链路 | 结果 |
| --- | --- |
| 默认开 | 目录计数 **idx=0/1**（同名 RAW 被过滤，`shots/misc-skip-on.png`） |
| 保存关 | 键 `true→false`，计数 **idx=1/2**（RAW 进入列表） |
| 取消链路 | 键未变（默认 true），计数 **idx=0/1** |
| 反向保存开 | 键 `false→true`，计数 **idx=0/1**（`shots/misc-skip-back-on.png`） |

### no_raw_load（不打开 RAW 图片文件）

样本：`Temp/set04c/raw/r.cr2`（无效 RAW，确保走失败路径，不被 JPEG 内容嗅探误判）。

| 链路 | 提示文案（右下角 Toast） |
| --- | --- |
| 默认关 | **「无法打开：RAW 解码失败」**（`shots/misc-noraw-default.png`） |
| 保存开 | 键 `false→true`，**「无法打开：已在设置中禁用 RAW 解码」**（`shots/misc-noraw-on.png`） |
| 取消链路 | 键未变（默认 false），回到 **「RAW 解码失败」**（`shots/misc-noraw-cancel.png`） |

| 项 | 结论 | 理由 |
| --- | --- | --- |
| `etc/pageturn_wav` | 跳过 | 音频输出，无可见界面变化；按「无可复现证据一律跳过」不硬做。仅补时长标注。 |
