## 3. 新口径下被替换 / 退场的旧回滚语义

1. **取消不再回滚普通项**：`reject()` 不再恢复快照；普通项已即时写盘，×/Esc 关闭即保留。
2. **普通项不再「保存时统一写盘」**：开关/下拉/输入走 `connectInstantSignals → applyInstantValue`，开关一改即写盘；场景 B 中关窗前 ini 已是 `always_on_top=true`。
3. **即时预览不再「预览后回滚」**：`applyLiveCheck()` 成功即写盘；仅失败时恢复控件与运行态（错误提示保留）。
4. **主题/磨砂不等色写盘**：等色分支与真实变色成功分支均即时 `sSet("theme", …)`，磨砂 `sSet("ui/blur_material", …)`；关闭（含「不保存」）保留。
5. **不存在两套互斥逻辑**：`grep takeSnapshot|restoreSnapshot|rollbackLiveSession|rollbackThemePreview|snapshot` → 0 命中；取回实现中未 reintroduce 快照回滚。
6. **页脚旧口径替换**：上一轮的「保存后生效 / 取消会恢复」已不存在；页脚为「普通设置即时生效；热键改绑与界面语言在保存后生效」（856、2539 行）。
