## 一、改法（对照交办单 §三）

| 交办单项 | 落实 |
|---|---|
| 3.1 统一场景矩形 | 新增 `ImageCanvas::updateSceneRect()`：`sceneRect = 图片矩形 ± 2×视口 padding`；`m_item` 保持 (0,0) 起、尺寸=图片逻辑尺寸，未用 `setPos`。调用点：`setPixmap`、`setPixmapPreservingView`、`resizeEvent`（交办单要求 3 处全落实） |
| 3.2 归一化基准 | `viewCenterNormalized()` / `setPixmapPreservingView` 锚点还原**本就按图片矩形**归一化（sceneRect 改动前已如此），天然满足；实测自检：fit 态 `report` 里 `center=0.4987/0.4979 ≈ (0.5,0.5)` |
| 3.3 顶部对齐 | `applyAlignTopIfLarge()` 与 `fitToWidthGeom` alignTop 分支的 `setValue(0)` → `centerOn(img.center().x(), img.top() + viewport()->height()/(2*z))` |
| 3.4 光标 | `setCropMode(false)` → `unsetCursor()`（非裁剪态交还 Qt 的抓手光标） |
| 3.5 长图轴锁 | 未做（交办单标可选，「做不了就跳过，不要为它增加风险」） |
| 附带 | `keepScenePointAt` 早退条件从「图片小于视口」改为「滚动条无行程」（fit 态现在有行程，旧条件会错误吞掉锚定） |

## 四、备注（后续测试/维护须知）

1. **滚动条可见**：sceneRect 加 padding 后滚动条有行程，大图窗口边缘会出现细滚动条——自由拖动的自然结果，非回归。
2. **测试伪影（脚本侧，非应用 bug）**：模拟鼠标步进会被合并吞约 1 步（~13-16px），`drag()` 已加 2px 引导步 + 终点重复步；x64 下 `SetWindowPos(HWND_TOPMOST)` 的 hWndInsertAfter 必须 `c_void_p(-1)`；T8 点击 y 必须落在箭头矩形物理带 ≈402-498。
3. **环境干扰**：测试期间桌面出现无关「ZCode 安装」弹窗与 IDE 抢前台（曾污染一轮数据，已识别排除），脚本已加前台守卫 + TOPMOST 规避。
4. 量测方法从「手选模板匹配」换成「白色像素质心」：big.png 白盘是全画面唯一白色大块，质心法无坐标歧义。
