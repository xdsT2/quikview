## 二、逐项改法与验收实测

### 1. 不允许有多个实例（`config/allow_multiple_instances`，inverted）— `e5a9baf`

- 改法：`src/main.cpp` 单实例 `serverKey` 由 `!Config::instance().allowMultipleInstances()` 决定；`debugRun` 继续绕过（`--smoke`/`--screenshot`/`--settings` 等不参与转发）。
- 实测：勾选（默认）→ 起窗口 A 再起第二实例：进程数恒 1、PID 前后一致、标题切到新图；取消 → 两独立窗口（进程数 2）。

### 2. 缓存下一张图片（`imageproc/cache_image`，def=true）— `35fe262`

- 改法：`preloadNeighbors` 开头 `if (!cacheNextImage()) return;`。
- 实测：关 → 翻页无预读任务（临时 qDebug 探针，已删）；开 → 有预读。

### 3. 缓存大小（`imageproc/cache_size_mb`，def=300）— `6723570`

- 改法：`Config::cacheSizeMb()`（clamp `[64, 4096]` 防呆）；`ImageCache::setFullCacheLimit(mb)`，构造读配置设初值；`applyRuntimeSettings` 保存后立即下发。只作用于原图缓存 `m_fullCache`，缩略图/拖动预览缓存 64MB 不变。
- 实测：64MB 与 1024MB 两态连开 30 张大图，`totalCost()` 均不超设定值，大值明显更少重解码（临时探针，已删）。

### 4. 单击屏幕两侧翻页（`mouse/click_side_pageturn`，def=true + 迁移）— `a6b281b`

- 改法：`ImageCanvas::mouseReleaseEvent` 在边缘翻页前判断 `sideClickPageturn()`；`etc/migrated_side_click` 一次性迁移——标记不存在时忽略旧值强制按 true 处理并写入标记（防老用户 config 里残留的 `false` 导致升级后莫名失效）。
- 实测（真窗 ctypes 脚本）：开 → 右缘点击翻页（截图 02.png）；关 → 不翻页；旧值 false 且无标记 → 升级后仍翻页且标记被写入；配置测试后还原。

### 5. 双击最大化 / 还原（`mouse/dblclick_maximize`，def=true）— `defd9c2`

- 改法：`ImageCanvas` 新增 `mouseDoubleClickEvent` → `emit doubleClickRequested()`；`MainWindow` 连接后 `isMaximized() ? showNormal() : showMaximized()`。与「侧边单击翻页」冲突处理：本项开启时边缘单击判定延迟 **220ms** 等第二击，220ms 内收到双击 → 取消翻页只最大化；本项关闭时保持**零延迟**翻页。
- 实测（真窗 ctypes 脚本，两态）：开 → 中央双击 showCmd 3↔1；边缘双击只最大化不翻页；边缘单击仍翻页；关 → 双击无效、单击零延迟翻页。

### 6. 禁用屏幕保护程序（`etc/disable_screensaver`，def=false）— `6a15681`

- 改法：`applyScreensaverPrevention(bool)`：开 = `SetThreadExecutionState(ES_CONTINUOUS | ES_DISPLAY_REQUIRED)`，关/析构 = `ES_CONTINUOUS` 还原；`applyRuntimeSettings` 下发。
- 实测（本次取到直接证据）：`powercfg /requests` 开态 DISPLAY 节出现 `...\quikview\build\quikview.exe`；退出后消失（仅剩 GameViewer 常驻请求）。另用临时探针验证构造启用+析构还原两态（探针已删后提交）。

### 7. 根据图片大小调节窗口（`etc/fit_window_to_image`，def=true）— `de090b7`

- 改法：`openFileFitting(path)`（置 `m_fitWindowPending` 复用 openFile）+ `fitWindowToImage()`（仅标记置位且开关开启时执行一次，resize = 图宽/高 + 铬开销 76+72+16，clamp 到可用屏 80% 并居中）。三条路径走 openFileFitting：命令行带文件、第二实例 IPC 转发、文件→打开；showImage 尾部统一调 fitWindowToImage。**翻页不改窗口**。
- 实测（DPI=1.25 按比值判定）：开 → 小图 800×600 → 窗口 1000×955（≈目标 800×764×1.25）、大图 4000×3000 → 2048×1104（=工作区 2560×1380 的 80%，clamp 正确）；关 → 1350×1019（默认 1080×815×1.25，未调）。回归冒烟 `win=800x764` 在 next10 中**逐行恒定**，证明翻页窗口尺寸不变。

### 8. 翻页音效（`etc/pageturn_wav`，def=false）— `8f6c180`

- 改法：匿名命名空间 `playPageturnTone()`——静态 lambda 首用**内存合成** 40ms / 2200Hz / 指数衰减正弦 WAV（8kHz / 16bit / 单声道，手工构造 RIFF/WAVE 头），`PlaySoundW(..., SND_MEMORY | SND_ASYNC | SND_NODEFAULT)` 播放；`onPrev/onNext` 在 loadAsync 后调用；CMakeLists WIN32 块链接 `winmm`。**零外部音频素材**。
- 实测：开 → 翻页合成 684 字节 WAV（40ms×8kHz×16bit 单声道，RIFF/WAVE/fmt 字节级校验：sampleRate=8000、channels=1、bits=16，探针已删）；关 → 不合成不播放。仓库新增音频文件数 0。

## 四、过程踩坑（供后续批次参考）

1. **配置写入**：PowerShell `-replace` 会把 `\\` 当单反斜杠，表象上「没替换成功」。
   此后统一 `[IO.File]::ReadAllText + .Replace()`（单反斜杠字符串）+ 无 BOM UTF-8 写回。
2. **冒烟必须带 `--screenshot`**：不带时进程不退出，`-Wait` 挂死。
3. **CMake 注释含乱码**：按注释锚点替换会失配，改用 `target_compile_definitions(...)` 短锚点。
4. **设置页截图**：PrintWindow 对 Qt 深色对话框抓出全黑（v1 弃）；改走应用自带
   `--settings --shot-delay <ms> --screenshot-ui <out.png>`，脚本趁延时点左侧导航切页；
   桌面被全屏 Chrome 覆盖时首击落空 → 点击前 `SetWindowPos(HWND_TOPMOST)` 钉住对话框 + `SetForegroundWindow` 再点（v3 定稿）。
5. **项 8 规格对齐**：初版 44100Hz + SND_FILENAME 临时文件，对照交接单改为
   **8kHz + SND_MEMORY 内存播放**，并就地修正原提交（amend，未 push）。
