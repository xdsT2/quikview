## 一、根因

### 1. 文案承诺了没有的能力

`src/MainWindow.cpp` 的「上一个/下一个 文件夹/压缩包」（4 处）暗示能翻压缩包内图片，
而 ZIP/CBZ 直读从未实现（`SettingsDialog.cpp:875/1325-1326` 的注释已注销相关设置项）。
0.4.0 不做 ZIP，所以文案必须退回「文件夹」，否则就是空承诺。

### 2. 卸载会删用户数据 + 会留残包

- 旧卸载节第一行就是 `RMDir /r "$INSTDIR"`：**一把推平**。
  便携模式的 `config.ini`（书签/设置）就在安装目录里，用户随手放进安装目录的图片也在，
  全部连带删掉。
- `RMDir /r` 前没有进程检查：程序在跑时部分 DLL 被占用删不掉，
  结果是「删一半、留残包、快捷方式指向空目录」。

顺带把「上一个」与「文件夹」之间那个多余空格去掉了（原串是 `上一个 文件夹/压缩包`，
直接删后缀会留成 `上一个 文件夹`，读起来像错字）。**这是本期唯一的「超出字面」改动**，
如监工侧要严格保留空格，只需改回 4 个字符串。

`SettingsDialog.cpp:875 / 1325-1326` 三处历史注释按单子要求**保留不动**。

### 2. 验收探针 `navmenu`

`--smoke navmenu:<out.png>`：弹右键菜单 →「浏览导航」子菜单并把它自身 `grab()` 成 png。
按子项文案里的「文件夹」定位子菜单（这两项是 `addMenuItem` 生成的纯展示项，
快捷键只是文本，没有真实 QShortcut，不能按快捷键找）。

### 3. 卸载重写（`packaging/quikview.nsi`，仍是 UTF-16LE+BOM）

顺序：

1. **占用检查** → 有进程就 `MessageBox` + `Abort`，什么都不删；
2. **按安装清单删自身文件** → `quikview-manifest.txt` 逐行 `Delete "$INSTDIR\$3"`；
3. `Delete "$INSTDIR\uninstall.exe"`（它由 `WriteUninstaller` 生成，不在清单里）；
4. **非递归** `RMDir` 六个插件目录 + `$INSTDIR`（有用户文件时静默失败，目录保留）；
5. 原有清理照旧：桌面 / 开始菜单两条 lnk、`Software\QuikView`、`Uninstall\QuikView`。

### 4. 安装清单（`tools/package.sh`）

staging 完成、压包之前生成 `quikview-manifest.txt`：`find` 出全部相对路径、
`/` 换 `\`、`LC_ALL=C sort`，一行一个（本期 78 项）。清单随 `File /r "${SRC}\*.*"` 一起装进
`$INSTDIR`，卸载时按它删。

## 三、踩到的三个坑（都已修，记下来免得重犯）

1. **`tasklist` 检测拦不住**。第一版用
   `nsExec::ExecToStack 'cmd /c tasklist /FI "IMAGENAME eq quikview.exe" … | find …'`，
   实测**没拦住**：卸载直接进入删除，把不占用的文件先删了 → 80 文件只剩 46 个，
   正是要防的「半删残包」。
   **改成语言无关的文件占用检测**：以追加方式 `FileOpen "$INSTDIR\quikview.exe" a`，
   正在运行的 exe 映像拿不到写句柄 → `${Errors}` 成立即中止。零外部依赖、不受代码页影响。
2. **NSIS `FileOpen` 只有文本模式**（`r|w|a`，写 `rb` 直接报 `Usage: FileOpen …`），
   文本模式会把 CRLF 转成 LF。第一版按 `StrCpy $3 $2 -2` 剥两个字符，
   结果每行多剥一个字母，`Delete` 全部落空（测试里表现为「卸完还剩 79 个文件」）。
   现在按 1 个字符剥 LF，再判一次末尾是不是 CR。
3. **卸载器自身不会被自动删除**（至少在本机的非提权启动路径下没有），
   残一个 `uninstall.exe` 导致空目录删不掉。补 `Delete "$INSTDIR\uninstall.exe"` 后干净。

另外记两条环境坑：
- 静默安装必须用**提权**的进程起（PowerShell `Start-Process -Wait`）；
  从 bash / 非提权 python 起 `setup.exe /S` 会「exit 0 但什么都不装」。
- 卸载器用 python `subprocess` 起（`uninstall.exe` 用 `Start-Process` 会被安全策略拦），
  带 `cwd` 指向安装目录。

## 五、已知限制

1. 占用检测靠「exe 写句柄被占」，覆盖的是**同一个安装目录里的 quikview.exe**；
   用户如果从别的目录跑便携版，不影响本次卸载（也不该拦）。
2. 老版本安装（没有 `quikview-manifest.txt`）走兜底分支：只删 `*.exe` / `*.dll` / `*.ico`
   与六个插件目录里的文件，其余（含旧包多带的 dll）可能残留，需要再删目录时手动处理。
   正常升级安装会写入新清单，不触发兜底。
3. 卸载器自身删除依赖 NSIS 常规路径；若 `uninstall.exe` 恰好被杀软锁定，会留一个文件 +
   非空目录（不删用户数据，属可接受降级）。
4. 静默卸载时提示框按 `/SD IDOK` 自动确认，不会挂住自动化；交互卸载正常弹框。
