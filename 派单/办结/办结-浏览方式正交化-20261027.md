# 交接：浏览方式正交化（第 6 期 v2）

> 对应 HANDOFF「新指令」第 6 期（2026-10-26 22:05，v2 全量重写）。根因：五项浏览方式被塞进同一个 exclusive `QActionGroup` + 单一 `m_viewMode` int，勾选态/画面/内部状态三者互相矛盾。
> 代码提交见下方「提交」；验收全部在终版二进制上重跑（`build/quikview.exe`，含全部改动后重新编译）。

## 一、改法（对应单子 6 条要求）

### 1. 状态拆分（`MainWindow.h`）

```cpp
// 浏览方式 = 两个正交维度：「缩放」与「双页」。别再加第三个复合枚举。
int m_zoomMode = 1;      // 0=原始 1=适合窗口 2=适合宽度
int m_spreadMode = 0;    // 0=关 3=双页左→右 4=双页左←右
```

- `isSpreadMode()` 改读 `m_spreadMode == 3 || m_spreadMode == 4`。
- `m_viewModeBeforeLock` → `m_zoomModeBeforeLock`：锁定只记忆缩放一维，双页不参与；解锁时还原并同步勾选态。
- 公开入口拆成 `setZoomMode(int)`（0/1/2）与 `setSpreadMode(int)`（0/3/4）；`setViewMode` 已删除，`main.cpp` 的 `--view=` 同步改名。

### 2. 菜单分组（`buildContextMenu`）

- 缩放三兄弟（原始大小/适合窗口/适合宽度）留在 exclusive `zoomModeGroup`。
- 双页两项**移出**互斥组：仍 checkable + 挂窗口快捷键，但由 lambda 统一走 `setSpreadMode`：

```cpp
connect(actTwoL2R, &QAction::triggered, this, [this]() {
    setSpreadMode(m_spreadMode == 3 ? 0 : 3);   // 点已勾项 = 取消双页
});
connect(actTwoR2L, &QAction::triggered, this, [this]() {
    setSpreadMode(m_spreadMode == 4 ? 0 : 4);
});
```

- 点未勾项=换方向、点已勾项=关；快捷键 7/6 走同一条 `triggered`，语义一致。

### 3. 显示 = f(双页, 缩放)

- 新增 `applyCurrentZoom()`：**只**按 `m_zoomMode` 适配（0→`zoomActual` / 1→`fitToWindow` / 2→`fitToWidth`）。
- `refreshSpread()` 的硬编码 `m_canvas->fitToWindow()` → `applyCurrentZoom()`；`showImage` 的双页分支同样删掉 `fitToWindow()`，单图/拼图统一走 `applyCurrentZoom()`。
- `showImage` 装图顺序同步改读 `m_spreadMode`（L2R/R2L 拼接方向）。
- **关双页必须还原单图**：`setSpreadMode(0)` 用 `showImage(readImageSync(m_currentPath), m_currentPath)` 重新装一次单图（顺带重置旋转/效果、元数据与标题对齐）——以前只改状态、画面留着拼图，正是「切换不回来」的来源。

### 4. 勾选态一致性硬规则

- 新增 `syncViewModeActions()`：把 5 个 QAction 的 checked 全部按 `m_zoomMode` / `m_spreadMode` 重算。
- 调用点：`setZoomMode`、`setSpreadMode`、`showImage` 装图后、`buildContextMenu` 每次弹菜单前、解锁缩放时。
- 效果：双页开着点「适合窗口」= `适合窗口✔ + 智能双页(左→右)✔` 两个都亮，画面=拼图按窗口适配。

### 5. 工具栏图标

`updateShowModeIcon()`：双页开传 `m_spreadMode`(3/4)，关传 `m_zoomMode`(0/1/2)；在 `setZoomMode` / `setSpreadMode` / 每次装图后都调。
（`ToolBar::setShowModeIcon` 仍是只存值不绘制的旧桩，本轮只保证传进去的值正确；`Chrome.h` 加了一个 `showModeIcon()` getter 专供 report 取证。）

### 6. 冒烟语义

- `fit` / `fitwidth` / `actual` → 只改缩放（`setZoomMode`），不动双页。
- `spread:l2r` / `spread:r2l` → 只改双页（直接设定，不 toggle，保证冒烟确定性）。
- 新增 `spread:off`；另加两个验收钩子：`spread:toggle`（触发 `actTwoL2R`，等价按 7 / 点已勾项）、`spread:toggle:r2l`（等价按 6）。
- 新增 `viewmenu`：直接弹出「浏览方式」子菜单，供 `--screenshot-ui` 截勾选态（勾选态只能截子菜单本身判定；按 `actTwoL2R` 定位，不依赖文案）。
- `report` 新增 `spread=` 与 `icon=` 字段；`mode=` 现在恒为缩放维度（0/1/2），`vm=` 保持旧口径（双页时 3/4，否则 0/1/2），旧探针不破。

## 三、口径与备注（给核验的人）

1. **关双页会重置旋转/效果**：`setSpreadMode(0)` 走 `showImage` 重新装原始单图。双页拼图本身开拼时就不保留单页旋转（拼图是重新读盘的），所以关掉时回到未旋转原始状态是与之一致的；如果你期望「关双页保留旋转」，需要另立一单（旋转态与拼图的兼容策略要单独定）。
2. **原版 Honeyview 的 toggle 语义未实测**：本机没有原版可跑，按 22:05 拍板「点已勾项=取消双页」实现；若后续实测原版不是 toggle，改 `setSpreadMode` 的 lambda 三行即可。
3. **工具栏图标**仍是「传值正确但不绘制」的旧桩，未新增绘制（不属本期范围）。
4. **冒烟新增命令**均为验收钩子：`spread:off`、`spread:toggle`、`spread:toggle:r2l`、`viewmenu`；`report` 多出 `spread=` / `icon=`。旧字段 `mode=`（现为纯缩放）与 `vm=`（旧复合口径）保持兼容。
