## 1. 目标

在 SET-02 框架上，把一小批**已证实可安全热更新**的二态设置项接成 LIVE，逐项验证后启用即时。不追求数量，不重写框架。用户最终要去掉统一「保存设置」按钮，但四条门槛未全绿，本单仍不删。

## 2. 选点规则（硬约束）

- **只从 SET-01 台账中已有 64 组 ON/OFF 双向行为证据的项里选**；78 项缺双向证据的一律不进本批。
- 本批 **3~5 项、同类 / 同页**，便于定位回归（按审计单 §7「每批只负责有限几个同类选项」）。
- 选点前逐项**先证明用户可见效果真实存在**，再接 LIVE。教训：`9c0c03e` 发现 `UiStyle.h` 全局 `QLabel{font-size:12px}` 覆盖 `#infoKey/#infoVal` 的 `setFont()`，「EXIF 小字体」档改前在信息面板从未生效——**配置有消费点 ≠ 真生效**。
- 明确排除：缓存开关 / 缓存大小（运行时缓存对象与在飞任务风险）、深 / 浅主题（SET-02 已判 UiStyle 重建 / 浅色分支回滚风险）、SET-01 的 P1 独立缺陷（边缘翻页默认值不一致、language 假开关候选等，另行派单）。
- 复用 `applyLiveSetting` / `restoreSnapshot` / `rollbackLiveSession` / `QUIKVIEW_TEST_LIVE_FAIL` 失败注入，不重写框架、不改 `onAccepted()` 的其余 ON_APPLY 保存路径。
- **LIVE 计数从 1 起**（EXIF 小字体已占 1），不得把 SET-02 成果算作 SET-03。

- 保留「保存设置」按钮与「更改会在保存后生效」文案；**四条删按钮门槛未全绿，禁止删 / 改名按钮**。
