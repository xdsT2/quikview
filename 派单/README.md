| 目录 | 前缀 | 谁写 | 含义 |
|---|---|---|---|
| `待办/` | `派单-<主题>-<日期>.md` | 监工侧 | 已开单、执行侧未办 |
| `待核验/` | `回执-<主题>-<日期>.md` | 执行侧 | 办完回传，等监工核验 |
| `办结/` | `办结-<主题>-<日期>.md` | 监工侧 | 核验通过，正式闭环 |
| `归档/YYYY-MM/` | `派单-` | — | 历史单据原件 |
| `规范/` | — | — | COMPAT-RULES、设计规范、发版说明、状态快照 |
| `证据/` | — | — | 截图与视觉基线对比（不入库） |

流转：监工写 `待办/派单-x.md` → 执行侧办完写 `待核验/回执-x.md` → 监工核验后改名 `办结/办结-x.md`。
