## 2. 每项验收点（逐项填表，缺一不可）

1. **ON/OFF 双向行为证据**：两态各一次真实行为触发，至少含反向切回；给触发前后截图（或像素差 / 运行态日志）与 ini 读回值。只记录配置变化不算通过。参考触发方式：#24 12MP JPEG 连按翻页录屏比对「先模糊后清晰」与「直接清晰」并给首帧时序日志；#27 透明 GIF 逐档看底色（含档 3 的一致性结论）；#28 透明 PNG 四档看底色与网格明暗；#29 缩到 25% 对比三档锯齿 / 锐度，首装不改设置时核对下拉与菜单勾选一致；#30 相邻大图翻页看淡入 / 滑动，同一图旋转不得触发。
2. **切换即预览**：设置对话框仍打开时变更该项，须有用户可见的即时反馈（见 §3）。条件依赖项不得沿用「会话内不可观察」结案。
3. **关闭即保留、不用保存**：不点「保存设置」，以正常退出路径离开设置页，配置值与运行态都保留；重启后读回一致。
4. **三链路运行态回滚**：分别走 取消 / Esc / 标题栏 ✕，配置值**与运行态**（解码首帧策略 / 透明底色 / 插值采样缓存 / 翻页过渡）同时回到进入设置前；非仅比对配置值。
5. **失败注入**：`QUIKVIEW_TEST_LIVE_FAIL=1` 下 UI、运行态、配置三者不分叉。
6. **回归**：「保存设置」旧路径不回归、批次01/02/03/04 既有 LIVE 项不回归、深 / 浅主题与 100% / 125% DPI 下相关状态截图；未测的格式样本 / 大图样本须单列。
7. **生效时机标注**：每项写清真实生效时机；footer 按 §1.1 第 4 条同步；#27 档 3 与 #26 禁用项必须消除「可操作假开关 / 假档位」。
8. 按 `docs/design/UI-REVIEW.md` 模板填报；未测项、未达标项单列并写清原因，**不得写成通过**；仅「配置落盘成功」或「控件状态更新」不构成通过。

## 3. 会话内可见性（总纲 §2，本批核心难点）

设置页为模态 `dlg.exec()`，主窗口交互被拦截；本批 5 项消费点又多在「下一次开图 / 下一次重采样 / 解码线程 / 装图路径」才读值，容易被误判为「会话内不可观察」而退回保存生效型。本批须：

- 为 5 个键补 `applyLiveSetting` 分支与运行态快照（复用 SET-02 框架，不另造轮子）；下拉项须在选项变更后即时下发对应 setter，并给运行态可见反馈（页内状态行或预览提示）。
- 给出**用户可见的即时反馈**（设置页内联状态行 / 预览提示，说明已即时生效及可观察的触发方式），或提供非模态预览入口；条件依赖项须写清观察前提并给出该前提下的实证。
- **不得只把控件换形态、只接上 setter、只写「会话内不可观察」或只做时机标注就算完成**；不得以「配置已写」冒充即时生效。这是总纲 §2 与 22:42 最高指令的硬要求。
