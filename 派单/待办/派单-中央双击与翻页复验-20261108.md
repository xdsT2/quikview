# 派单 · 中央双击最大化与翻页交互复验

日期 2026-11-08 · 待办 · 无对应回执（首次开单）

来源：`派单/待办/派单-发布前工作区交接-20261108.md` 的「左右侧边翻页」段——**前一轮中央双击最大化自动化验证未通过**，交接要求「最终构建须前台复验」。本单把这个模糊项拆成可测的四条，并补上缺失的探针。

## 一、先说清为什么「自动化验证未通过」

现有冒烟探针 `clickb:`（`src/MainWindow.cpp:2869`）只投递**一次**按下+松开，走的是 `ImageCanvas::mouseReleaseEvent` 的单击路径：

```
clickb:left|x|y      画布视口坐标，投递 press → release
```

**没有任何探针能产生 Qt 的 `MouseButtonDblClick` 事件**。所以「中央双击最大化」根本没法用探针验，只能靠人手点——上一轮报「自动化验证未通过」，实际是「没有可用的自动化手段」，不是功能坏了。

## 二、任务 A：补双击探针（必做，先做）

在 `src/MainWindow.cpp` 的冒烟命令链里新增：

```
dblclickb:left:<x>:<y>     画布视口坐标 (x,y)
```

必须按 Qt 真实的双击事件序列投递，顺序不能少：

1. `QEvent::MouseButtonPress` @ (x,y)
2. `QEvent::MouseButtonRelease` @ (x,y)
3. `QEvent::MouseButtonDblClick` @ (x,y)   ← **关键，缺这一步双击逻辑永不触发**
4. `QEvent::MouseButtonRelease` @ (x,y)

投递方式沿用 `clickb:` 现有的写法（`QCoreApplication::sendEvent(m_canvas->viewport(), &ev)`，或 `QTest::mouseDClick` 等价实现）。中间**不要**插 `processEvents` 之外的延时——双击判定依赖 `QApplication::doubleClickInterval()`，超过间隔 Qt 会当成两次单击。

验收：`--smoke "dblclickb:left:400:300,keygeom"` 之类的组合能跑通不崩，且退出码 0。

## 三、任务 B：四条交互复验（每条都要留证）

| # | 场景 | 期望 | 判定方式 |
|---|---|---|---|
| B1 | 画布**中央**双击（`dblclickb:left:画布中心`） | 窗口 `showMaximized()`，图像**不翻页、不缩放** | 用探针前后各打一次窗口几何 + `m_dir->index()`；index 不得变化，`isMaximized()` 为真 |
| B2 | 已最大化时中央双击 | `showNormal()`，还原到原尺寸，图像不翻页 | 同上，`isMaximized()` 为假 |
| B3 | **侧边**双击（左右热区各一次） | 按**两次**翻页（QGraphicsView 双击序列 = 两次点击），不最大化 | index 前后差 2（或到边界停住），`isMaximized()` 为假 |
| B4 | 中央**拖动**（press→move→release，位移 >3px） | 不翻页、不最大化 | index 不变，`isMaximized()` 不变 |

**B1 是重点，必须先想清楚一件事**：
`mouseReleaseEvent`（`src/ImageCanvas.cpp:1163-1175`）在 `delta == 0`（非边缘）时会派发**左键映射动作**（`mouseActionRequested(leftAct)`）——如果用户把左键映射设成「下一张」，那么中央双击会先翻一张、再最大化。历史上靠「边缘单击延迟 220ms 等第二击」来挡这个，而交接单说这个延迟**已被去掉**（`src/ImageCanvas.cpp` 已无 220 相关代码，`MainWindow.cpp:1881` 的注释还留着旧说法）。

所以 B1 必须在**两种左键映射**下各测一次：
- `mouse_left_action=none`（默认）→ 期望：只最大化，不翻页
- `mouse_left_action=next`（翻页）→ 期望：**只最大化，不许先翻一张**

如果第二种情况下 index 变了，那就是 bug，本单必须修：在 `mousePressEvent` 记下位置与时间，`mouseDoubleClickEvent` 里若判定为「同一位置双击」，回滚掉第一次点击已产生的动作（或延后派发单击动作到双击间隔之后）。**修完重测 B1 两条。**

B4 的拖动判定已有基础：`isClick` 要求位移 `manhattanLength() < 3`，验证它确实生效即可。

## 四、任务 C：设置项联动复验

侧边点击翻页受 `config/mouse/click_side_pageturn` 控制（`ImageCanvas.cpp:1178`、`1192`）。三条：

| 开关 | 侧边单击 | 侧边双击 |
|---|---|---|
| 开（默认） | 翻 1 页 | 翻 2 页 |
| 关 | 不翻页（箭头仍显示） | 不翻页、不最大化 |

复验方式：改配置 → 重启 → `clickb:` / `dblclickb:` 各跑一次，记录 index 变化。
