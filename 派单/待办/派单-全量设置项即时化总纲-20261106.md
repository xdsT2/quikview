- 本单为**可领的总纲**。领单后按页 / 按作用对象**连续开批单**（`派单/待办/派单-<批名>-<日期>.md`），每批沿用 SET-02 `applyLiveSetting` / `restoreSnapshot` / `rollbackLiveSession` / 失败注入 `QUIKVIEW_TEST_LIVE_FAIL` 框架，不为每项另造轮子。

- **批次必须连续开到 105 项全覆盖**；「队列非空 / 一次只开一张 / 不强凑数量 / 同页合格批次 0 组」不得作为停止理由。单写者、每项单独 commit、每项冒烟、隔离配置、双向行为证据、UI-REVIEW 验收记录照旧。
