## 1. 目标（三条，缺一不可）

1. **切换即预览**：设置页外观区拨动「跟随系统 / 浅色模式」时，主窗口与设置页配色立即变化，不需点「保存设置」。
2. **关闭即保留、无需保存**：以「确定 / 关闭 / 标题栏 ✕」正常退出设置页即保留本次主题选择，不再要求用户额外点保存按钮。
3. **取消 / Esc / 标题栏 ✕ 可回滚**：明确区分「保留」与「放弃」两条退出路径，放弃时配置值与运行态（含 QSS / 令牌重建后的状态）都逐像素回到进入设置前。

用户 2026-11-06 11:41 口径：「不用保存，用户体验才最佳」。这是**硬目标**，不是可选优化；当前仍保留「保存设置」按钮只是因为四门槛未全绿，不是目标变更。

## 3. 前置评估（§3.1 收紧条款，必须先做、逐项书面给结论）

1. `Theme::applySetting` 在同一会话内**反复切换**（深→浅→深→跟随系统）是否稳定、无残留 QSS / 调色板污染。
2. 会话快照能否覆盖 **UiStyle 重建后的运行态**（不是只覆盖配置值）；取消 / Esc / ✕ 后运行态与配置值是否同时回到进入前。
3. 「跟随系统」开启时浅色开关禁用态互斥、`installSystemWatcher` 与手动切换的优先级是否冲突。

**任一不满足时的处理（不得越线）**：须提交可复现原因 + 像素级证据 + ① 回滚修复方案、② 另立单计划、③ 临时过渡态说明，并报监工侧；**不得据此结案、不得把「保存后生效」当最终形态**。回退后「保存后生效」只能是**标注清楚的临时过渡态**，回执须明确写「即时预览未实现 / 未验收」，即时化作为遗留硬目标继续排队。
