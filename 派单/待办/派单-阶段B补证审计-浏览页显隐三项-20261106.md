## 3. 每项验收点（逐项填表，缺一不可）

| 验收点 | 要求 |
|---|---|
| **开/关双向** | 两态各做一次真实行为触发，至少包含反向切回；给出触发前后的截图（或像素差）与配置读回值。只记录配置变化不算通过。 |
| **会话内可见** | 设置对话框仍打开时，主窗口上能否观察到该变化。可观察的给出截图/像素差；**由模态拦截而不可观察的**（需 Shift+TAB、真实悬停、重新开图等）必须写「不可」并说明阻断原因，**不得写成通过**。此列直接决定下一批按「即时预览型」还是「保存生效型」验收。 |
| **三条链路运行态回滚** | 分别走 取消 / Esc / 标题栏 ✕：配置回到进入设置前的值，运行态（浮层/Tooltip/帧号行）回到进入设置前的状态；三条链路都要有 ini 读回与截图。 |
| **保存后重启读回** | 点「保存设置」→ 退出进程 → 用同一份隔离 ini 重开 → 设置值与行为仍成立（截图 + ini 读回）。 |
| **隔离配置** | 全程 `QUIKVIEW_CONFIG_PATH` 指向 `派单/证据/阶段B补证-浏览页显隐三项/cfg-*.ini`；运行前后记录 `build/config.ini` SHA256，确认用户配置未被改写。 |

### 3.1 各项触发细节

1. **overlay_filename**：主窗口打开一张图 → Shift+TAB 隐藏菜单 → 截图（文件名浮层应出现，设置 ON）/（应无浮层，设置 OFF）；再 Shift+TAB 切回菜单 → 截图确认浮层消失与菜单恢复。
2. **show_anim_control**：打开多帧 GIF（自动播放格式）→ 读信息浮层文本中的「第 n/N 帧」行；ON（不显示）应无该行，OFF（显示）应有该行。MNG/多页 TIFF 不适用（台账注释：只作用于自动播放格式）。
3. **show_tooltip**：`SetCursorPos` + `ClientToScreen` 把真实光标移到画布/标题区，等待超过 Qt tooltip 延迟；ON（不显示）应无 Tooltip，OFF（显示）应出现。每态至少一张截图，必要时放大裁切。
