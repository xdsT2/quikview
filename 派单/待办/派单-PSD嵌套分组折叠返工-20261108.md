### 根因（代码锚点）

`src/LayerPanel.cpp` 用单个变量记录「最近一次遇到的 groupStart」，不按深度栈匹配父子，且组行无条件显示：

- `preferredHeight()` 第 206、210、212 行
- `rebuild()` 第 257、262-263、277 行

```cpp
int currentGroup = -1;
for (int i = m_doc.layers.size() - 1; i >= 0; --i) {
    if (L.groupEnd) continue;                 // 边界标记被直接跳过，没有出栈
    if (L.groupStart) { currentGroup = i; /* 组行永远显示 */ continue; }
    if (currentGroup >= 0 && L.groupDepth > 0 && m_collapsed.value(currentGroup, false))
        continue;                             // 只认"最近一个组"，父组信息已被覆盖
    ...
}
```

两处症状由同一根因产生：倒序遍历遇到「组 1」时 `currentGroup` 被改成 9，父组 2 的折叠状态丢失；`L.groupEnd` 被 `continue` 跳过，没有恢复父组的时机。`preferredHeight()` 复制了同一口径，折叠后面板高度同样算错。

### 修法

用深度栈，两处共用同一份「可见行」判定，不要再各写一遍：

- 倒序遍历，维护 `QVector<int> stack`：
  - `groupStart`：先判断栈中是否存在已折叠组 → 有则不显示本行；然后无论显示与否都 `stack.push_back(i)`
  - `groupEnd`：`stack.pop_back()`（不要 `continue` 跳过）
  - 普通层：栈中存在已折叠组 → 跳过
- `preferredHeight()` 不要复制逻辑，直接统计 `rebuild()` 生成的可见行数（或抽出 `QVector<int> visibleLayerIndexes()` 两边共用）

正确性自检（用上面的样本跑一遍）：
- 折叠组 2：可见行 = 组 2、卡通人物、背景2、背景1、桥（共 5 行 + 整图）
- 折叠组 1（组 2 展开）：可见行 = 组 2、箭头、天气、圆2、圆1、组 1、毛玻璃、卡通人物、背景2、背景1、桥
- 两层都折叠：可见行 = 组 2、组 1（折叠加固）、卡通人物、背景2、背景1、桥
