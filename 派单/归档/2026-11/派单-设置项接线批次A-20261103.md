## 三、逐项规格

### 1. 不允许有多个实例

- **键**：`config/allow_multiple_instances`，UI `inverted=true`、`def=false`（勾选 = 不允许多开 = 默认行为）
- **现状**：`src/main.cpp:185` `if (!debugRun) { serverKey = singleInstanceKey(); ... }` —— 无条件单实例，第 13 期就是这么验收的
- **改法**：
  ```cpp
  const bool singleInstance = !Config::instance().allowMultipleInstances();
  if (!debugRun && singleInstance) { serverKey = singleInstanceKey(); /* 探活 + 转发 */ }
  ```
  关闭时 `serverKey` 留空即可 —— `main.cpp:207` 已有 `if (!serverKey.isEmpty())` 分支，天然不监听、不转发。
- **坑**：调试参数（`--smoke` / `--screenshot` / `--settings` 等）必须继续绕过单实例，这段 `debugRun` 判断不要动。
- **验收**：
  - 勾上 → 起窗口 A，再双击另一张图：**进程数恒 1、PID 前后一致、标题切图**；
  - 取消 → 连开两次：**进程数 2**，两个独立窗口。

### 2. 缓存下一张图片

- **键**：`imageproc/cache_image`，`inverted=false`、`def=true`
- **现状**：`src/MainWindow.cpp:1642` 和 `:1645` 无条件 `m_cache->preload(files.at(...))`
- **改法**：`Config` 新增 `bool cacheNextImage() const`（默认 `true`），两处 preload 前加判断。
- **验收**：关掉后翻页 → 无预读任务（可临时加 `qDebug() << "[preload]"` 观察后删除，或加一个 `--smoke` 探针）；开着 → 日志有预读。
- **注意**：关闭预读会让连续翻页略慢，这是设计后果，不要顺手改 FIFO 调度。

### 3. 缓存大小

- **键**：`imageproc/cache_size_mb`，设置页 `QSpinBox` 范围 10–100000、加载默认 **300**
- **现状**：`src/ImageCache.cpp:12` `m_fullCache.setMaxCost(256 * 1024 * 1024);` 硬编码
- **改法**：
  - `Config` 新增 `int cacheSizeMb() const`，默认 300，**clamp 到 `[64, 4096]`** 防呆；
  - `ImageCache` 新增 `void setFullCacheLimit(int mb)`，构造时读配置设初值；
  - `MainWindow::applyRuntimeSettings()` 里调用该 setter，**保存后立即生效**。
- **范围**：只作用于**原图缓存** `m_fullCache`；缩略图与拖动预览缓存保持 64MB 不变。
- **坑**：不允许做成「重启才生效」，那等于把灰项换成了另一个坑。
- **验收**：设 64MB → 连开 30 张大图；设 1024MB → 同样操作。两次的 `m_fullCache` 占用（可临时输出 `totalCost()`）都不超过设定值，且大值明显更少重解码。

### 4. 单击屏幕两侧时翻页

- **键**：`mouse/click_side_pageturn`，`inverted=false`、`def=false`（**但见下方迁移**）
- **现状**：`src/ImageCanvas.cpp:929-937` `edgeTurnDelta(event->pos())` 恒开
- **改法**：`Config` 新增 `bool sideClickPageturn() const`，**默认 `true`**（当前行为就是恒开，默认必须保持）；`ImageCanvas` 在 emit `edgeTurnRequested` 前判断。
- **必须做一次性迁移（重点）**：  
  该键历史上被 `addCheckUnavailable` 绑进 `m_chkBinds`，而保存设置时**所有绑定的键都会写盘**（`SettingsDialog.cpp:1502-1505` 没有跳过禁用控件）。也就是说**老用户的 config.ini 里这个键很可能已经是 `false`**。  
  规则：`etc/migrated_side_click` 标记不存在时，**忽略旧值、强制按 `true` 处理**，并写入标记；标记存在后才以配置为准。  
  不做这一步，老用户升级后侧边点击会莫名失效，而且他会以为是 bug。
- **验收**：
  - 新建配置（无键）→ 侧边点击能翻页；
  - 手工把键写成 `false` 且无标记 → 升级后**仍能翻页**，且标记被写入；
  - 在 UI 里取消勾选 → 侧边点击不翻页。

### 5. 双击最大化 / 还原

- **键**：`mouse/dblclick_maximize`，`inverted=false`、`def=true`
- **现状**：画布没有 `mouseDoubleClickEvent`；`src/MainWindow.cpp:182` 已有 `isMaximized() ? showNormal() : showMaximized()` 同类逻辑可复用
- **改法**：
  - `ImageCanvas` 新增 `mouseDoubleClickEvent`，左键 → `emit doubleClickRequested()`；
  - `MainWindow` 连该信号 → `isMaximized() ? showNormal() : showMaximized()`。
- **必须处理与「侧边单击翻页」的冲突**：  
  Qt 的事件序列是 press → release → dblclick → release，**双击的第一击已经会触发一次边缘翻页**。要求：
  - 本项**开启**时，边缘翻页的单击判定延迟 **220ms** 等第二击；
  - 220ms 内收到双击 → **取消翻页，只做最大化**；
  - 本项**关闭**时，保持现在的**零延迟**翻页（不许为省事给所有单击统一加延迟）。
- **验收**：
  - 图片中央双击 → 最大化 ↔ 还原，各 3 次；
  - 边缘热区内双击 → **只最大化，不翻页**（这是本项最容易翻车的地方）；
  - 关掉本项 → 边缘单击**立即**翻页（用秒表或日志时间戳证明没有 220ms 延迟）。

### 6. 运行 QuikView 时禁用屏幕保护程序

- **键**：`etc/disable_screensaver`，`inverted=false`、`def=false`  
  |  |  |  
  | --- | --- |
- **改法**：开关开时启动即 `SetThreadExecutionState(ES_CONTINUOUS | ES_DISPLAY_REQUIRED)`；关闭选项或程序退出时 `SetThreadExecutionState(ES_CONTINUOUS)` 还原。头文件 `<windows.h>` 已有先例（`src/main.cpp:23`）。
- **验收**：管理员终端 `powercfg /requests`，开启时能看到 `QUICKVIEW.EXE` 的 `DISPLAY` 请求，关闭后请求消失。若环境不允许看 `powercfg`，退化为断言 `SetThreadExecutionState` 返回值非 0 并记录日志。

### 7. 根据图片大小调节窗口大小

- **键**：`etc/fit_window_to_image`，`inverted=false`、`def=true`
- **改法**：`Config` 新增 `bool fitWindowToImage() const`（默认 `true`）。  
  **只在两条路径生效**：
  1. 命令行带文件启动（`main.cpp:256` 的 `positionalArguments()` 路径）；
  2. 「文件 → 打开」。  
     按图片尺寸 + 当前铬件高度 resize，clamp 到可用屏幕的 **80%**。
- **绝对不允许**：翻页时改窗口大小（每张图窗口都跳，是灾难）。
- **验收**：打开 4000×3000 → 窗口放大；打开 320×240 → 窗口缩小；连续翻 10 张 → **窗口尺寸一个像素都不变**。

### 8. 翻页时播放音效

- **键**：`etc/pageturn_wav`，`inverted=false`、`def=false`
- **改法**：**禁止引入任何外部音频素材**（授权风险）。运行时合成 40ms 衰减正弦（8kHz / 16bit / 单声道 WAV 字节流，含 RIFF 头），调用
  ```cpp
  PlaySound(reinterpret_cast<LPCWSTR>(wavBytes.constData()), nullptr,
            SND_MEMORY | SND_ASYNC | SND_NODEFAULT);
  ```
  `CMakeLists.txt` 链接 `winmm`（Windows 平台）。
- **验收**：开启 → 翻页有短促「咔」声、连翻 10 次不卡顿、不叠加爆音；关闭 → 静音；**仓库新增音频文件数必须为 0**（`git status` 里不应出现任何 `.wav`）。
