## 三、批次 B（12 项）

### B1. 保存缩放状态

- **键**：`view/save_zoom_state`（`inverted=false`、`def=false`）
- **现状**：无 accessor，重开文件永远按 `default_zoom`（fit）
- **改法**：`Config` 加 `bool saveZoomState() const`；在 `MainWindow` 的「记录每张图状态」处按路径存 `zoom`（QSettings 里另开一组 `zoom/<hash>` 或 `QHash<QString,double>` 序列化），打开文件时若开关开则恢复，否则回落 `defaultZoom()`
- **验收**：开 → 放大到 300% 关窗重开同一张，仍是 300%；关 → 重开回到 fit

### B2. 不显示鼠标悬浮工具提示

- **键**：`view/show_tooltip`（`inverted=true`、`def=true` → 默认显示提示）
- **现状**：各处 `setToolTip` 硬编码
- **改法**：`Config` 加 `bool showTooltip() const`；在 `MainWindow` 构造末尾统一遍历子控件 `setToolTip("")`（关闭时），或封装 `applyTooltips()` 在 `applyRuntimeSettings` 里调用
- **验收**：关 → 悬停命令栏按钮/胶囊无浮层；开 → 恢复（切换后不重启也应生效）

### B3. 图片大于窗口时显示图片顶部

- **键**：`imageproc/align_top_when_large`（`inverted=false`、`def=true`）
- **现状**：fit 时居中
- **改法**：`Config` 加 `bool alignTopWhenLarge() const`；`ImageCanvas` 的 fit 计算里，当图片高度 > 视口高度时把 `scroll` 定位到顶部（`verticalScrollBar()->setValue(0)`），否则居中
- **验收**：开长图（1000×6000）→ 首屏看到图片顶部；关 → 垂直居中

### B4. 最大书签数

- **键**：`bookmark/max_bookmarks`（combo：10/20/30/50/100）
- **现状**：`Config::toggleFavorite` 只 prepend，无上限淘汰
- **改法**：`Config::toggleFavorite` 追加超过上限时从尾部淘汰；上限读 `maxBookmarks()`（默认 50，clamp 到 10~100）
- **验收**：设 10 → 连加 15 个书签，菜单里只剩 10 个且最早的最先消失

### B5. 在边角显示通知信息，而非中心

- **键**：`config/notify_corner`（`inverted=false`、`def=true`）
- **现状**：`Config::notifyCorner()` 已存在但零消费，toast 恒顶部居中
- **改法**：`UpdateNotifier` / toast 定位读该配置：开 → 右下角；关 → 顶部居中
- **注意**：默认 `true` 意味着**上线后 toast 默认位置从居中变成右下角**，属预期行为变化，写进交接文档
- **验收**：开 → 右下角；关 → 顶部居中；两种位置都不遮胶囊

### B6. 不显示动画信息控制

- **键**：`view/show_anim_control`（`inverted=true`、`def=true`）
- **现状**：动图进度/控制条恒显示
- **改法**：`Config` 加 `bool showAnimControl() const`；动图状态条按它显隐
- **验收**：关 → 播 GIF 时无动画控制条；开 → 恢复

### B7. 不显示缩放信息控制

- **键**：`view/show_zoom_control`（`inverted=true`、`def=true`）
- **现状**：缩放百分比浮层恒显示
- **改法**：同上，`showZoomControl()`
- **验收**：关 → 滚轮缩放时不弹百分比；开 → 恢复

### B8. 用小字体显示 EXIF / 文件信息

- **键**：`view/exif_small_font`（`inverted=false`、`def=false`）
- **现状**：信息面板字号固定
- **改法**：`Config` 加 `bool exifSmallFont() const`；信息面板/胶囊文字字号在 11px / 10px 两档切换
- **验收**：开 → 字号变小、不截断；关 → 恢复

### B9. 自动保存当前图片路径为书签

- **键**：`bookmark/auto_bookmark`（`inverted=false`、`def=false`）
- **现状**：书签只能手动 `B`
- **改法**：`Config` 加 `bool autoBookmark() const`；开关开时，`openFile` 成功后自动 `toggleFavorite`（注意：切图频繁会刷书签，需**只在「打开」路径触发，不在翻页触发**，且已存在则不重复写）
- **验收**：开 → 打开 3 张图，书签菜单多 3 条；关 → 打开不产生书签

### B10. 不打开 RAW 图片文件

- **键**：`etc/no_raw_load`（`inverted=false`、`def=false`）
- **现状**：libraw 已接（`CMakeLists.txt:22` 的 pkg-config）
- **改法**：`Config` 加 `bool noRawLoad() const`；解码入口判断，开时对 RAW 直接返回「不支持的格式」并给出明确提示
- **验收**：开 → 打开 `.nef` 提示不支持；关 → 正常解码

### B11. 打开 JPEG 时不同时打开同名 RAW

- **键**：`etc/skip_raw_when_jpg`（`inverted=false`、`def=true`）
- **改法**：目录扫描（`DirectoryLoader` / `MainWindow` 取文件列表）时，若同名 `.jpg` 存在则过滤掉 `.nef/.cr2/.arw` 等同名 RAW
- **验收**：同目录放 `a.jpg` + `a.nef`，开列表 → 只有 `a.jpg`（开关关闭 → 两个都在）

### B12. 打开 RAW 图片文件时，显示已有缩略图

- **键**：`etc/raw_thumbnail`（`inverted=false`、`def=true`）
- **现状**：libraw 全图解码慢
- **改法**：解码 RAW 时优先取内嵌 JPEG 预览（libraw 的 `unpack_thumb`），成功则先上屏，再后台解全图；失败回落全解
- **验收**：开 → 打开 24MP RAW 首屏时间明显短于关闭时（记录两个耗时数字）

## 四、批次 C（14 项，按优先级）

### C1. 使用图片文件的 ICC 设置

- **键**：`imageproc/image_icc`（`inverted=false`、`def=true`，当前是 `setEnabled(false)` 手工灰）
- **改法**：`Config` 加 `bool imageIcc() const`；解码后 `QImage::colorSpace()` 若不是 sRGB 且开关开 → `convertToColorSpace(QColorSpace::SRgb)`。Qt6 现成 API，无需第三方库
- **验收**：找一张 Display P3 / AdobeRGB 图，开关开 → 色彩与系统看图器一致；关 → 明显偏艳/偏灰（用同屏对比截图证明）

### C2. 使用监视器的 ICC 设置

- **键**：`imageproc/monitor_icc`（`def=false`）
- **前置要求**：需要拿到系统显示器 profile（Windows 走 `GetICMProfile` / WCS）。**允许判定为「暂不可行」并保持灰显**，但必须在交接文档写清：试了什么 API、为什么拿不到。**禁止**硬编码 sRGB 假装实现
- **验收**：能拿到 profile → 转换链路生效；拿不到 → 保持灰显 + 文档说明

### C3. 为 GIF 图片使用透明背景

- **键**：`imageproc/gif_transparent`（combo 0/1/2/3）
- **改法**：`Config` 加 `int gifTransparent() const`（默认 0）；`ImageCanvas` 合成时按档位铺底：0 默认调色板、1 白、2 黑、3 自定义色
- **验收**：四档逐一切换，透明区域底色随之变化

### C4. 为 32 位图片使用透明背景

- **键**：`imageproc/img32_transparent`（combo 0/1/2/3）
- **改法**：同上，0 棋盘格、1 白、2 黑、3 深色网格
- **验收**：打开带 alpha 的 PNG，四档底色正确；棋盘格不随缩放抖动

### C5. 更改默认背景图片

- **键**：`view/bkgnd_image`（bool）+ `view/bkgnd_image_path`（路径行，当前整行 `markUnavailable`）
- **改法**：`ImageCanvas` 新增 `setBackgroundImage(path)`，`paintEvent` 里在纯色之上绘制；提供「平铺 / 拉伸 / 居中」三档（可用现有 combo 样式）
- **验收**：设一张图 → 画布铺满；清空 → 回到纯色；换主题色不影响

### C6. 翻页效果

- **键**：`imageproc/pageturn_fx`（combo 0 无 / 1 淡入淡出 / 2 Alpha 滑动 / 3 滑动）
- **改法**：`ImageCanvas` 翻页切换时按档位做过渡（`QVariantAnimation` 驱动 opacity / offset）
- **硬约束**：**滑块连续预览路径必须禁用动画**（否则拖动滑块会卡）；动画时长 ≤ 150ms；与 L905 的"平滑缩放"不叠加
- **验收**：四档逐一切换可见差异；连续快速翻 10 张不卡顿；拖滑块无动画

### C7. 显示主窗口

- **键**：`view/show_main_window`（`def=true`）
- **注意**：**语义待确认**。原版这一项的准确含义需查 Honeyview 设置页实测（可能是「启动时显示主窗口」或「托盘模式」）。确认不了就**不要实现**，改为从界面删除并在交接文档说明理由——不要凭空猜一个行为
- **验收**：若实现，按确认的语义给出对应场景前后对比

### C8. 顶端菜单隐藏时显示文件名 (Shift+TAB)

- **键**：`view/overlay_filename`（`def=false`）
- **改法**：胶囊/命令栏隐藏时，画布中央顶部叠加文件名与序号，3 秒淡出；`Shift+TAB` 触发
- **验收**：`Shift+TAB` → 文件名出现 → 3s 消失；胶囊可见时按无效

### C9~C12. 鼠标按键映射（左键 / 右键 / X 键 / Y 键）

- **键**：`mouse/btn_left`、`mouse/btn_right`、`mouse/btn_x`、`mouse/btn_y`（combo，`def="none"`）
- **现状**：`buildMousePage` 里 `configurable=false`，映射写死在 `ImageCanvas` 事件里
- **改法**：引入一张 `按键 → 动作` 派发表（`QHash<Qt::MouseButton, Action>`），`mousePress/Release` 统一查表；`XButton1`/`XButton2` 需处理 `Qt::XButton1/2`
- **硬约束**：左键默认仍是「拖动平移」，必须保留「<3px + <300ms 判定点击」的既有语义，否则边缘翻页与双击最大化（第 14 期刚做的）会回归失败
- **验收**：每键改成「翻下一张」→ 点击生效；改回 `none` → 无动作；**回归**：边缘单击翻页、中央双击最大化、中键全屏切换三项都不能坏

### C13. 使用强锐化滤镜

- **键**：`imageproc/strong_sharpen`（`def=false`）
- **改法**：在 `lanczosResample`（`ImageCanvas.cpp:78`）之后接一层 3×3 unsharp mask，强度固定（不做滑块）
- **验收**：开 → 缩图边缘更锐、无白边振铃；关 → 与现在一致；48MP 图缩图耗时增幅 ≤ 20%（记录两个数字）

### C14. 先显示低品质图片以加速渲染

- **键**：`imageproc/preview_mode`（`def=true`）
- **改法**：解码分两级：先出内嵌缩略图 / 半尺寸预览上屏，再后台解全图替换；要复用现有 FIFO 调度，**不许另起线程池**
- **验收**：开 → 24MP RAW 首屏 < 200ms，全图随后无闪烁替换；关 → 一次出全图；连翻 10 张无错位（旧图不能盖新图）
