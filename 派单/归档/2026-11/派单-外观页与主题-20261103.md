## 2. 提交二：主题三档（含跟随系统）

### 配置模型（一个键，别开两个键打架）

- `config/theme` ∈ `system | dark | light`
- **默认仍是 `dark`**，不改现有默认——老用户升级后不会突然变浅色
- `Config::theme()` 保留字符串返回；新增 `bool isFollowSystem() const { return theme() == "system"; }`

### 生效路径

1. `Theme.h` 加：
   ```cpp
   inline Mode resolveMode()
   {
       const QString t = Config::instance().theme();  // 或传参，避免 Theme 依赖 Config
       if (t == QLatin1String("system"))
           return QGuiApplication::styleHints()->colorScheme() == Qt::ColorScheme::Dark
                      ? Mode::Dark : Mode::Light;
       return t == QLatin1String("light") ? Mode::Light : Mode::Dark;
   }
   ```
   （依赖方向自己拿捏：`Theme` 不要反向 include `Config` 造成环，可以改成 `resolveMode(QString)`。）
2. `main.cpp:84` 与 `MainWindow.cpp:3869` 改调 `resolveMode`。
3. 系统监听：`Theme::installSystemWatcher(QApplication&)`，connect `QStyleHints::colorSchemeChanged`，回调里**只在当前 `theme == "system"` 时**才重新 `apply`；连接只建一次，重复调用不重复 connect。

### 必须处理的三个坑

- `Theme::apply` 是**全量重设 stylesheet**：切换前先 `QApplication::closeAllPopups()`，否则已弹出的菜单/浮层会保持旧配色或出现半透明残影。
- 设置页、胶囊、信息面板里若有硬编码深色（`#232427` 一类），切浅色后**不许出现黑字黑底/白字白底**；已知设置页恒深色，本单不修，但必须保证可读、不崩。
- 菜单项 `actDark` 的勾选态在 `system` 模式下要显示**实际**深色；用户点它 → 写 `theme = dark|light`（显式退出跟随系统），设置页开着时同步刷新。

### 验收

- `theme=system` 时在 Windows 设置里切深浅 → **3 秒内**主窗、菜单、胶囊跟随，不重启。
- 切到 `dark` 后再改 Windows 设置 → 不再跟随；切回 `system` → 恢复跟随。
- 三档来回切 5 次，菜单/胶囊/信息面板无残留（截图对比）。
- 重启程序后仍是上次选择。

## 4. 提交四：磨砂材质

### 范围（用户拍板）

- 右键菜单与所有子菜单（`buildContextMenu` 系列返回的 `QMenu`）
- Tab 信息浮层（`MetadataPanel`）
- **不含**主窗口、不含设置对话框

### 技术路线（逐级降级，全失败就保持纯色，不许报错弹窗）

1. Win11 22H2+：`DwmSetWindowAttribute(hwnd, DWMWA_SYSTEMBACKDROP_TYPE=38, &3 /*TRANSIENT*/, 4)`，同时 `DWMWA_USE_IMMERSIVE_DARK_MODE=20` 设 1。
2. 失败回退：`SetWindowCompositionAttribute` + `ACCENT_ENABLE_ACRYLICBLURBEHIND(4)`，`GradientColor = 0x9927292D`（ARGB）。
3. 再失败：`DwmEnableBlurBehindWindow`。
4. 全失败：不透明，继续用现有样式。

所有 API 用 `GetProcAddress` 动态取，**不新增链接库、不改 CMake 依赖**。

### 样式配合

- `UiStyle::styleSheet()` 增加 `bool blur` 形参：`blur ? "QMenu { background: rgba(39,41,45,0.72); ... }" : "QMenu { background: #27292d; ... }"`，其余行不变。
- 新增 `UiStyle::applyBlurToPopup(QWidget *w)`：取 `w->winId()`，按上面路线尝试；`polishMenu()` 与 `MetadataPanel::showEvent` 各调一次（仅在 `ui/blur_material` 为真时）。
- 开关切换后：重设全局样式表 + 已存在的弹窗**下次 show 时**生效即可（不必强刷已关闭的窗口）。

### 硬约束

- 不能因为透明而丢掉 1px 边框与 8px 圆角（QSS 的 `border` / `border-radius` 必须保留）。
- 不许给菜单加 `WA_TransparentForMouseEvents`。
- 开/关 20 次，GDI/USER 对象数不持续增长（任务管理器或 `GetGuiResources` 自测，数据写进交接文档）。
- 磨砂关闭时，菜单必须与现在**像素级一致**（截图对比）。

### 验收

- 开：右键菜单区域能透出后面的图片且**明显模糊**（截图里能看出背景色调、看不清网格线）。
- 开：Tab 信息浮层同样（背景是图片而不是纯色块）。
- 关：完全不透明（与改前截图对比一致）。
- Win10 或 API 全失败：菜单为不透明纯色、不崩溃、不弹错误。
