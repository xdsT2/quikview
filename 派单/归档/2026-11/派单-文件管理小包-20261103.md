## 1. 文件重命名（模板 + 预览）

### 入口与快捷键

- 菜单「文件 → 重命名…」，快捷键 **F6**（F2 是「打开」副键、F3 书签、F4 关闭、F5/F9 设置，F6 空闲；已核）
- 右键菜单同项（无冲突）

### 范围

对话框顶部二选一：**仅当前文件**（默认）/ **当前文件夹全部**（按当前排序，只含图片文件）

### 模板变量（写在文件名框里）

| 变量 | 含义 | 示例 |
|---|---|---|
| `{name}` | 原名（不含扩展名） | `IMG_0001` |
| `{index}` | 序号，默认 1 起，可补零 `{index:03}` | `001` |
| `{date}` | 文件修改日期 `yyyyMMdd` | `20261103` |
| `{time}` | 文件修改时间 `HHmmss` | `231530` |
| `{ext}` | 原扩展名小写（不带点）；不写则自动保留 | `jpg` |

默认模板 `{name}`（等于不改名）；支持中英文、空格、`#` 等合法字符。

### 预览

- 列表显示前 20 条「旧名 → 新名」（超出显示「…共 N 项」）
- 冲突行整行标红：目标已存在（Windows 大小写不敏感，`A.jpg` 与 `a.jpg` 视为冲突）、含非法字符 `\/:*?"<>|`、空文件名、总长 >255

### 执行

1. **先全量校验**：任何一条冲突 → 整个对话框禁止「确定」，底部红字列出冲突原因
2. 校验通过后逐条 `QFile::rename`；中途失败立刻停止，toast 报「已完成 N 项，第 N+1 项失败：原因」
3. 成功后刷新目录列表，并把当前选中定位到改名后的文件
4. 不做撤销；Esc/取消无任何副作用（校验阶段不改文件）

## 2. 旋转后自动保存（默认关）

- 设置·图像处理新增「旋转后自动保存」`etc/rotate_save`，默认 **false**；行尾提示：「开启后旋转会重写原文件（JPEG 将重新编码）」
- **开**：旋转 / 水平翻转 / 垂直翻转动作后，把 `m_sourceImage` 按当前几何（`m_netRotation` + `m_flipH/V`）烘焙，写回原文件，EXIF Orientation 归一为 1
  - 写失败（只读、被占用、权限）→ toast 提示，保留视图状态，不崩溃
  - 不支持自动保存的格式：RAW / 多页 TIFF / 动图 → 跳过并 toast「该格式不支持自动保存」
- **关**：维持现状（仅视图变换，不碰文件）
- 写入前用 `QSaveFile`（原子替换），避免写一半损坏原图

## 3. 从剪贴板取图（Ctrl+V）

- 菜单「文件 → 从剪贴板打开」，快捷键 **Ctrl+V**（当前未被占用）
- 分支：
  1. 剪贴板有图像数据（截图工具 / 网页复制图）→ 存临时 PNG（`QStandardPaths::TempLocation`，文件名前缀 `quikview-clip-`）→ 走正常打开链路
  2. 剪贴板是本地文件 URL（资源管理器 Ctrl+C 文件）→ 取第一个受支持的图片文件打开
  3. 都没有 → 无动作（或 toast「剪贴板里没有图片」）
- 临时文件不进入目录列表、不写历史；启动时清理超过 1 天的 `quikview-clip-*.png`

## 4. 锁定窗口大小

- 菜单「视图 → 锁定窗口大小」勾选项（放「总在最前」附近即可）
- **开**：`setFixedSize(当前尺寸)`；**关**：恢复 `setMinimumSize` / `setMaximumSize` 为原值
- 与「根据图片大小调节窗口大小」互斥：锁定期间不调窗
- 持久化 `etc/lock_window_size`，默认 false；重启恢复
- 无边框模式 / 全屏切换后仍然生效（全屏时忽略锁定，退出全屏恢复）
