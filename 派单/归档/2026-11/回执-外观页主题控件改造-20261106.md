## 3. 语义与落盘

| 操作 | `theme` 值 | 控件表现 |
|---|---|---|
| 跟随系统开 | `system` | 「浅色模式」禁用并显示系统解析值（深色=关 / 浅色=开），标签与说明灰显 |
| 跟随系统关 + 浅色开 | `light` | 浅色开关可用、开 |
| 跟随系统关 + 浅色关 | `dark` | 浅色开关可用、关 |
| 历史 `theme=dark` | 关 / 关 | 深色 |
| 历史 `theme=light` | 关 / 开 | 浅色 |
| 历史 `theme=system` | 开 / 系统解析值 | 深色系统=关，浅色系统=开 |

跟随开启期间切 Windows 深浅色：设置页与主窗口即时跟随，禁用开关同步刷新（`QStyleHints::colorSchemeChanged`）。
跟随关闭时以「浅色模式」当前值决定；该值在跟随期间被同步为系统解析值，不会出现禁用假开关。

## 8. 风险与说明

- 「跟随开启时浅色开关被同步为系统解析值，关闭跟随沿用该值」：与单据 §2.1 的表格一致，
  但若用户期望「关闭跟随回到自己上次手选的主题」，当前实现不保留该值。单据未要求保留，
  如需保留需新增一个内存态 `m_lightManual`，建议另开单。
- 失败注入文案沿用 SET-02 的通用注入文本（「信息面板拒绝本次字号切换」），只在测试路径出现；
  真实主题应用失败路径当前只有非法值防御，不会在 UI 上触发。
